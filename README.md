# 🎖️ نبرد تانک‌ها — بازی دو نفره آنلاین

بازی تانک‌بازی دو نفره، آنلاین، فقط با HTML/CSS/JavaScript خالص (بدون نیاز به سرور بک‌اند).
اتصال بین دو بازیکن با WebRTC (کتابخانه [PeerJS](https://peerjs.com)) به‌صورت مستقیم (peer-to-peer) برقرار می‌شه، پس این پروژه یک سایت کاملاً استاتیک هست و روی **GitHub Pages** به راحتی دیپلوی می‌شه.

## قوانین بازی
- صفحه بازی ۱۰×۱۰ خونه‌ست.
- هر بازیکن ۳ تانک داره:
  - 🛡️ **قدرتی**: جون ۳ | دمیج ۱ | حرکت ۱ | برد شلیک ۲
  - ⚡ **سرعتی**: جون ۲ | دمیج ۲ | حرکت ۴ | برد شلیک ۲
  - 🎯 **اسنایپر**: جون ۱ | دمیج ۳ | حرکت ۱ | برد شلیک ۴
- موانع (سنگر و سیم خاردار) به‌صورت رندوم روی نقشه پخش می‌شن. سنگر جلوی حرکت و شلیک رو می‌گیره؛ سیم خاردار فقط جلوی حرکت رو می‌گیره.
- اول بازی هر بازیکن تانک‌هاش رو در نیمه خودش می‌چینه.
- حرکت و شلیک فقط در ۴ جهت (بالا/پایین/چپ/راست) و در حد مجاز هر تانک ممکنه (کمتر از حداکثر هم مجازه).
- هر نوبت، هر تانک زنده یک کار می‌تونه بکنه: یا حرکت، یا شلیک.
- با صفر شدن جون، تانک نابود می‌شه؛ با نابودی هر ۳ تانک یک بازیکن، اون بازیکن می‌بازه.

## ساختار پروژه (قابل توسعه)
افزودن تانک جدید در آینده خیلی ساده‌ست — فقط کافیه در `js/tanks-config.js` یک آیتم به `TANK_TYPES` و یک کلید به `ROSTER` اضافه کنی؛ بقیه‌ی بازی (منطق، رندر، شبکه) بدون تغییر باهاش کار می‌کنه.

```
tank-game/
├── index.html
├── style.css
├── js/
│   ├── tanks-config.js   ← تعریف انواع تانک (اینجا رو برای اضافه‌کردن تانک جدید ویرایش کن)
│   ├── game-logic.js     ← قوانین بازی (حرکت، شلیک، برد، مانع، برنده)
│   ├── network.js        ← لایه اتصال آنلاین (PeerJS/WebRTC)
│   ├── render.js         ← رسم صفحه روی canvas
│   └── main.js           ← اتصال UI + شبکه + منطق بازی
└── README.md
```

## دیپلوی روی GitHub Pages
1. یک ریپازیتوری جدید توی گیت‌هاب بساز (مثلاً `tank-game`).
2. تمام فایل‌های همین پوشه رو (با همین ساختار پوشه‌ای) به ریپو push کن:
   ```bash
   git init
   git add .
   git commit -m "init tank game"
   git branch -M main
   git remote add origin https://github.com/USERNAME/tank-game.git
   git push -u origin main
   ```
3. توی گیت‌هاب برو به **Settings → Pages**.
4. زیر «Build and deployment»، گزینه **Source** رو روی `Deploy from a branch` بذار و شاخه `main` و پوشه `/ (root)` رو انتخاب کن، بعد **Save**.
5. بعد از حدود یک دقیقه، آدرس بازی این شکلی در دسترس می‌شه:
   `https://USERNAME.github.io/tank-game/`

## نحوه بازی آنلاین
1. یک نفر روی «میزبانی بازی» می‌زنه و کدی که نشون داده می‌شه رو برای نفر دوم می‌فرسته.
2. نفر دوم روی «پیوستن به یک بازی» می‌زنه و اون کد رو وارد می‌کنه.
3. بعد از اتصال، هر دو نفر تانک‌هاشون رو در نیمه خودشون می‌چینن و بازی شروع می‌شه.

> نکته: چون اتصال از نوع peer-to-peer هست، هر دو نفر باید به اینترنت وصل باشن؛ در شبکه‌های خیلی محدود (فایروال سخت‌گیر شرکتی و مشابه) ممکنه نیاز به تنظیمات اضافه (TURN server) باشه.

## اجرای محلی برای تست
چون فایل‌ها ماژول ES نیستن، کافیه با یک سرور استاتیک ساده اجرا کنی (باز کردن مستقیم فایل با `file://` هم معمولاً کار می‌کنه):
```bash
npx serve .
# یا
python3 -m http.server 8080
```
